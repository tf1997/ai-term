# 会话命令授权与界面动效

## 复合命令自动执行

包含命令替换、变量和多段查询的命令无法用一个程序名前缀精确授权。新增“本会话允许此命令”，用户确认后只允许整条内容相同的命令自动执行，不把它转换为宽泛的 `mysql`、`sh` 等前缀规则。

- 授权仅存在于内存，绑定连接、AI 会话、终端及连接代次。
- 命令内容改变、切换会话/终端、重连或面板卸载后，需要重新确认。
- 输入区显示已授权数量，可以随时撤销。
- 敏感命令、风险规则、sudo、危险环境变量、写入重定向和历史展开等限制继续生效。
- 前缀“总是允许”及其持久化方式保持原有行为。

## 动效与布局

- 连接/设置侧栏与辅助工具面板：进入 180ms、退出 140ms，使用 transform 和 opacity。
- 侧栏内容切换采用短淡出/淡入；常用编辑、确认、代码预览、关于等弹窗使用 160ms 过渡。
- 关闭停靠面板前记录宽度，退出时脱离网格，避免先缩为零宽度；布局只改变一次，不逐帧动画化 width/height。
- 退出中的侧栏和辅助面板使用 inert，避免不可见控件接收输入。
- 尊重系统“减少动态效果”设置；不常驻 will-change，不新增动画轮询器。
- 浅色终端的外层、边距、画布周围及底部快捷命令栏统一纯白，边界改为中性细线。

## 验证

运行时测试覆盖完整数据库查询命令、相同命令复用、内容变化、撤销、连接代次变化及不可自动授权的命令。浏览器验证授权按钮及撤销入口。

性能浏览器夹具同时验证：浮层侧栏开关不触发终端 resize，关闭时焦点隔离、终端实例保留，宽屏左右停靠面板退出时保持原宽度，减少动态效果时关闭过渡，终端边距和底栏实际计算背景色为白色。

测试入口：`npm run test:scripts`、`npm run test:ai-browser`、`npm run test:terminal-debug-browser`、`npm run test:performance-browser`、`npm run test:ui`、`npm run test:architecture`、`npm run build`。浏览器测试使用模拟 IPC 和真实 Vue/xterm，不能等同于真实网络性能结论。
