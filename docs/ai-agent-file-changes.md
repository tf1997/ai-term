# Agent 文件变更

任务结束后的排列为 Worked、最终总结、文件列表。Worked 默认收起，展开显示按执行顺序记录的思考和步骤。文件列表显示任务内的净增删行数，点击文件打开带原行号、新行号和上下文的差异；代码保持 12px / 18px。长差异分批显示，每次 400 行，复制按钮导出完整 unified diff。

## 采集和统计

- 模型在 `run_command.files` 中声明本次命令的全部明确写入目标，使用绝对路径。未声明的写入无法保证被记录；此功能不是文件系统监控器。
- 风险检查和批准完成后，在任务绑定的同一个 POSIX 终端里只读采集执行前、执行后的文件内容。读取通过内部哨兵通道，支持已有的 SSH / 容器终端上下文，不使用本机路径猜测远程文件。
- 文件内容以 Base64 传输，保留 UTF-8 BOM、CRLF、尾部空白和文件末尾是否换行。缺失、空文件、读取失败为不同状态。
- 同一任务中重复修改同一文件，保留第一次执行前的内容，比较最后一次执行后的内容。统计不包含该任务之前已有的修改。检测到步骤之间文件变化、终端环境变化、停止或缺少完整快照时，显示原因并排除该文件的统计。
- 重命名按旧路径删除、新路径新增记录，需在工具参数中声明两个路径。
- 原始快照只用于界面和会话持久化，不加入模型的工具结果或上下文。内部读取不进入应用命令历史；Bash 内部命令清理兼容 macOS 自带 Bash 3。

## 范围

当前支持普通 UTF-8 文本文件。单个文件最多 64 KiB，一次读取最多 256 KiB，一个任务保存前后内容总计最多 2 MiB、最多 100 个文件记录。目录、符号链接、二进制、非 UTF-8、敏感路径、超限或读取失败均显示无法比较，不生成近似数字。

文件修改命令需要前台执行并等待写入结束。后台作业在快照采集后继续写入的内容、未声明的写入，以及历史任务没有采集的内容不包含在差异里。快照表示采集时观察到的内容；它不能隔离其他进程在同一次命令执行期间并发写入的影响。模型指令要求环境切换与修改分开执行。

记录保存在消息 `payloadJson.agentFileChanges` 中，通过 `normalizeAgentFileChanges` 恢复并校验大小。旧消息保留写入目标到执行记录的入口，不回填不存在的历史快照。

## 验证

- `npm run test:ai`：快照解析、真实 sh / bash / zsh 读取、精确 diff 的 patch 往返、重复修改、重试基线、停止、审批和会话恢复。
- `npx tsx --test tests/terminal/agent-file-capture.test.mjs tests/terminal/deferred-agent-command.test.mjs tests/terminal/agent-sentinel-capture.test.mjs tests/terminal/internal-terminal-output.test.mjs`：真实 shell 经原始哨兵通道读取，并验证隐藏输出、提示符等待、终端绑定和历史保护。
- `npm run test:ai-browser`：真实 Vue 界面，模拟模型和终端边界；覆盖 Worked、统计、差异行号、复制、焦点恢复、缺失快照和持久化恢复。
